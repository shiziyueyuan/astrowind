# 第 5/10 轮：第一份项目档案

用户选择先加入已有的小论文项目，并模糊个人隐私。

## 内容依据与边界

依据已有研究稿与此前项目整理记录，人工重写公开案例“石拱桥轮廓研究”，只保留一般研究问题、候选模型、算法过程、带条件的观察及下一步。

- 不包含真实姓名、年龄、学校、竞赛、具体地点、精确日期、协作者信息或原始文件路径。
- 不包含原始照片、原论文、答辩文件、精确测量值、独有数据表或可回溯的参考文献列表。
- 图是独立生成的标准化数学示意，明确标注不是研究对象的测量数据。
- 对现有描点的模型排序仅转述稿中观察，保留误差、假设和待复核条件；没有重新运行原研究实验。
- 不宣称获奖、发表、应用落地、实际结构安全，或未经确认的个人与协作分工。
- 保留 AI 辅助参与资料、代码、排版的说明。

## 实现

独立 project Markdown 集合，草稿默认不生成。公开条目使用非身份化 translationKey；中、英、日各一份。ARCHIVE 窗口展示项目卡片，跳转三语详情页。详情页提供阅读目录、数学示意、主题切换、语言切换和返回桌面。返回时恢复同一标签页的窗口布局。

本轮仍为本地开发，没有推送或部署。原模板参考页面后续轮次清理。
