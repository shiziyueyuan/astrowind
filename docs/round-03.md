# 第 3/10 轮：设计系统与三语架构

## 设计系统

`src/assets/styles/desktop.css` 定义纸面、窗口、文字、强调色、边线、字号、动效与响应式布局。浅色使用白与浅绿，深色使用近黑与橙。窗口和导航共享同一组语义变量。

首次显示前读取主题偏好，减少主题闪烁；系统偏好变化时，仅在“跟随系统”模式更新。语言与主题存储均为可选能力，浏览器禁用存储时仍可使用。

桌面使用排版、细线、点阵、抽象轨道与窗口形成探索感。移动端入口按阅读顺序排列。所有窗口可通过按钮与键盘打开、Escape 或关闭按钮关闭；焦点进入窗口并在关闭后返回触发按钮。减少动态效果偏好会关闭动画。

## 三语路由

| 路径  | 用途                                         |
| ----- | -------------------------------------------- |
| `/`   | 浏览器语种识别；提供无 JavaScript 的三语链接 |
| `/zh` | 简体中文桌面，`lang=zh-Hans`                 |
| `/en` | 英文桌面，`lang=en`                          |
| `/ja` | 日文桌面，`lang=ja`                          |

`src/i18n/index.ts` 统一管理语言类型、URL 与识别规则。先采用有效的手动语言偏好，再按浏览器的语言优先顺序匹配 `zh`、`en`、`ja`，全部未匹配时使用中文。直接访问某种语言的链接会保留该语言。切换语言保留当前窗口位置与查询参数。

`src/i18n/dictionaries.ts` 通过 `satisfies Record<Locale, Dictionary>` 约束三语键一致。五区域的文字在每种语言内完整定义，不用另一语言的文本补缺。

入口品牌名称固定使用「时咨月圆 / Shea」。ENTRY、IDENTITY、ARCHIVE、LAB、SIGNAL 为用户确认的统一区域标识。

## Markdown 内容基础

新增独立的 `journal` 内容集合，与 AstroWind 原有 `post` 集合分开。文件位于 `src/data/journal/{zh,en,ja}/`，使用同一个 `translationKey` 关联三语版本。`locale`、`title`、`kind` 为必需字段，`draft` 默认 `true`。

现有三篇同组草稿只记录本项目确实发生的初始化与设计基础工作；未提供公开博客详情路由，待博客轮次再接入发布列表、详情页、分类、RSS、翻译完整性与正式发布校验。
