# 桌面布局与开场动画补充

用户于 2026-10-23 要求加入开场动画，将初始界面改成电脑桌面风格。本次作为既有设计和交互轮次的修改，保留十轮开发流程和当前项目档案。

## 桌面

顶部系统栏保留线上别名、语言与主题选择，并显示访客本地时间。五个主要区域使用桌面图标与快捷 Dock；单击即可打开对应窗口。桌上文件直接进入已经确认的研究与视频项目。中间采用代码绘制的品牌壁纸，右侧为欢迎便笺。

自由拖动、多窗口置顶、关闭、整理、键盘移动和布局恢复继续使用原窗口控制器。可拖动边界调整到系统栏与底部 Dock 之间，保持入口与关闭按钮可达。手机使用紧凑布局，正文窗口独立滚动。

## 开场

首次进入桌面播放约 2.2 秒的启动动画，随后约 0.3 秒淡出；支持“跳过开场”、Escape 和“重播开场”。同一标签页刷新、切换语言或从项目返回时跳过；直接访问窗口锚点时也直接进入目标窗口。

尊重减少动态效果偏好，自动直接进入桌面。开场只在本地浏览器播放，没有声音或外部媒体请求。播放期间桌面不可交互，键盘焦点留在跳过按钮；结束后恢复焦点。禁用 JavaScript 时桌面不会被开场遮挡；模块加载失败时有自动显示桌面的兜底。

三语文案位于 src/i18n/shell.ts。研究与视频内容、媒体资源、公开身份边界及未确认的联系方式保持既有规定。当前仍为本地开发，没有推送或部署。
