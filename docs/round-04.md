# 第 4/10 轮：多窗口自由拖动

用户选择多窗口同时打开并自由拖动。本轮完善实验桌面的探索交互。

## 操作

- ENTRY、IDENTITY、ARCHIVE、LAB、SIGNAL 可以同时打开；再次点击入口会将对应窗口置顶。
- 拖动标题栏移动窗口。正文可选择、滚动，关闭按钮不会触发拖动。
- 点击窗口或在窗口内使用键盘，会将该窗口置顶；各窗独立关闭。
- 标题栏支持方向键移动，每次 8 像素；Shift 为 32 像素，Home 回到默认位置。
- 在窗口内按 Escape 关闭该窗口；焦点转到剩余的前台窗口或原入口。
- “整理窗口”将已打开的窗口重新错开放置。
- 手机与触屏保留标题栏拖动；正文保持纵向滚动。屏幕旋转、缩放或可见视口改变时重新约束窗口位置。
- 同一标签页使用 sessionStorage 保留窗口顺序和位置，切换语言或刷新后恢复。浏览器禁止存储时仍可使用窗口。

## 实现

窗口使用非模态 dialog，背景、导航与其他窗口始终可操作。标题栏使用 Pointer Events 统一鼠标、触控笔和触摸输入；拖动包含指针捕获、取消、失焦及丢失捕获时的清理。

窗口尺寸与位置受当前可见视口限制，保留边距，使标题栏和关闭按钮可达。长内容在窗口内部滚动。恢复的会话数据只接受已知区域和有限数值坐标。

`src/utils/desktop-windows.ts` 提供位置约束、层级顺序与会话校验。`src/components/desktop/desktop-controller.ts` 管理窗口、输入和语言切换时的状态保存。全部操作提示提供中文、英文和日文。
