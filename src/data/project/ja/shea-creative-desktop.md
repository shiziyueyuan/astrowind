## どんなふうに入ってきてほしいか

このサイトは「时咨月圆 / Shea」の作品や考えを置く場所として始まりました。ゲームを探索するときのように、訪れた人が入口を選び、いくつかの窓を開き、好奇心の向く方へ進める場所を目指しました。

そうしてホーム画面は、少しずつ実験的なデスクトップになりました。ENTRY、IDENTITY、ARCHIVE、LAB、SIGNAL の五つの入口が、歓迎、自己紹介、作品、実験、連絡先につながります。窓は自由に動かし、同時に開いておけます。作品や文章には、それぞれ読むためのページがあります。

## 要望を、次に見える変化へ

今回の Vibe Coding は、既存のテンプレート上で選択と修正を重ねる制作でした。公式のオープンソース AstroWind を基盤に、AI がコンポーネント、スタイル、設定の実装を補助し、私は画面への要望を通して方向を決めました。窓を自由に動かしたい、起動時のアニメーションがほしい、最初の画面をパソコンのデスクトップらしくしたい、といった要望です。

その後、フォント、SHEA のワードマーク、アイコンの配色も調整しました。中国語・英語・日本語にはそれぞれ適した無料のオープンソースフォントを採用。ライトテーマは白と淡い緑、ダークテーマは黒とオレンジです。初期設定はシステムに合わせ、手動でも切り替えられます。一つの要望を具体的な変更にして、また画面に戻って確かめる。その繰り返しでした。

## 作品にも、書きかけの考えにも場所を

作品記録には、個人情報に配慮してまとめた石造アーチの輪郭研究、続いて空白謎解きグループの共同制作映像を追加しました。過程と協力の範囲を残し、共同の成果を個人だけの実績として扱わないようにしています。

LAB には Vibe Coding、Vibe Videoing、日々の記録を置けます。ローカル執筆室で Markdown を読み込み、下書きを保存し、プレビューを確認してから公開サイトに同期できます。公開ページは閲覧専用で、コメントや返信はありません。連絡先も実際の使い勝手に合わせて調整し、うまく動かなかったメールリンクを、各アカウントを同じ扱いでコピーできる形式に変更しました。

## ローカルの画面から、共有できる URL へ

公開作業では、ローカルで開けることに加え、公開先のリンク、フォント、メディアを確認する必要がありました。GitHub Pages のリポジトリ用サブパスに、三言語のページやスクリプト、動画の URL を合わせています。動画のアップロードでは通信がタイムアウトしましたが、分割して転送し、展示版の画質と内容を保ったまま完了しました。

初版を GitHub Pages に公開し、オンラインのビルド、三言語のページ、フォント、動画のリソースを確認しました。現在は[公開入口](https://shiziyueyuan.github.io/astrowind/)からデスクを開けます。

## まずは、この版を外へ

まだ更新途中の Demo です。作品や文章、操作の細部はこれからも増やしていきます。この記録には今の姿と、一つの要望が実際に開いて探索できるサイトになるまでの修正を残しておきます。
