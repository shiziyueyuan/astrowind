## 先想清楚，想让人怎样走进来

这个网站的起点，是给「时咨月圆 / Shea」做一个展示作品和想法的地方。我希望它带一点游戏里的探索感：访客可以自己选择入口，打开几个窗口，沿着好奇心往下走。

于是，首页逐渐变成了一张实验桌面。ENTRY、IDENTITY、ARCHIVE、LAB、SIGNAL 是五个入口，分别连接欢迎、身份、作品、实验与联系。窗口可以自由拖动，也可以同时打开；作品和文字有各自的阅读页。

## 把反馈变成下一次看得见的改动

这次 Vibe Coding 是在现有模板上持续做选择。以官方开源 AstroWind 为基础，AI 辅助实现组件、样式和配置，我通过一轮轮反馈决定方向：窗口要能自由拖动，进入时要有开场动画，初始界面要更像电脑桌面。

随后继续调整字体、SHEA 字标和图标配色。中文、英文、日文分别采用适合的免费开源字体，浅色用白与浅绿，深色用黑与橙，主题默认跟随系统，也能手动切换。一次反馈对应一次具体改动，再回到页面里看效果。

## 给作品，也给没写完的想法留位置

作品档案先放入经过隐私处理的石拱桥轮廓研究，再加入空白解谜组的协作影像。呈现时保留制作过程与协作边界，不把共同完成的内容写成个人独立成果。

LAB 则容纳 Vibe Coding、Vibe Videoing 和日常记录。博客支持在本机写作间导入 Markdown、保存草稿、预览后同步公开网站。公开页面只供阅读，不设置评论或回复。联系入口也根据实际使用调整成并列的账号复制，不再依赖无法正常使用的 mailto。

## 从本地预览，走到一个能分享的网址

上线时才更直观地看到：本地能打开，还需要确认发布后的链接、字体和媒体都能找到。GitHub Pages 使用仓库子路径，三语页面、脚本和视频地址需要一起适配。视频上传还遇到了网络超时，之后通过分批传输完成，保留原有展示版的画质与内容。

首版发布到 GitHub Pages，并核对了线上构建、三语页面、字体和视频资源。现在可以从[公开入口](https://shiziyueyuan.github.io/astrowind/)进入这张桌面。
